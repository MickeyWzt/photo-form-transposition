# Photo Form Transposition v1.1 design

Version 1.1 replaces subject-first target selection with a source-led decision system.

1. Classify the photograph as mass-led, flow-led, topology-led, or hybrid.
2. Retain two to four dominant carriers and select one keystone carrier.
3. Compare candidate targets through an explicit carrier-to-form role map.
4. Estimate the amount of anatomy that would have to be invented.
5. Choose a contained, permeable, or gestural architecture.
6. Apply a minimal completion budget and an architecture-specific quality gate.

The revision was informed by tests on mountain, ocean, tree-shadow, desert-dune, forest-waterfall, and winding-road photographs. The new system deliberately treats a complete contour as valid when internal source roles are coherent, while requiring cross-boundary continuity only for permeable compositions.
