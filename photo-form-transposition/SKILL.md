# Photo Form Transposition

Create two simultaneous readings: a recognizable target form and a still-perceptible source photograph. Make the source structures perform the target instead of using the photograph as decorative fill.

## Preserve the source contract

- Treat the uploaded photograph as the sole visual-content source unless the user explicitly authorizes more imagery.
- Inspect the source before choosing a target. If the file is local, view it before invoking an image-editing tool.
- Preserve source identity through actual texture, light, color, depth, rhythm, and spatial direction.
- Do not add text, logos, frames, or unrelated objects unless requested.

## Run the workflow

1. **Classify the source.** Read [references/visual-system.md](references/visual-system.md). Decide whether the source is `mass-led`, `flow-led`, `topology-led`, or `hybrid`; retain only two to four dominant carriers.
2. **Find the keystone.** Identify the single source feature that can carry the target's main axis, hinge, sweep, body curve, or structural spine. If no keystone exists, avoid a highly specific target.
3. **Compare candidates.** Generate three to six target candidates, map each carrier to a target role, estimate completion cost, and choose the candidate that feels reasonable without explanation. If the user names a target, test its fit before using it.
4. **Choose the architecture.** Use `contained` for coherent internal mapping, `permeable` for field continuity, or `gestural` for directional expansion. Do not force every result to dissolve its boundary.
5. **Set strength and budget.** Default to `balanced`. Choose `subtle`, `balanced`, or `assertive`, then set a small completion budget for source-compatible edge or separation cues.
6. **Compile the prompt.** Read [references/prompt-compiler.md](references/prompt-compiler.md). State the source type, keystone, carrier-to-form role map, architecture, recognition anchors, completion budget, and invariants.
7. **Generate non-destructively.** Use an available image-generation or image-editing tool with the source attached. Save project-bound outputs with a new versioned filename.
8. **Inspect and revise once.** Read [references/quality-gate.md](references/quality-gate.md). Check normal and thumbnail views, apply the chosen architecture's gate, then revise only the dominant failure.

## Keep creative freedom disciplined

- Choose at most one primary transformation grammar and one supporting treatment.
- Use slicing, repetition, offset, frame echoes, grain, or print texture only when they reinforce a carrier.
- Prefer low-anatomy or archetypal forms when a specific species requires many independent body parts.
- Permit a mostly complete contour in `contained` only when at least three source regions perform distinct target roles.
- Build `permeable` fusion through continuous source material, not a uniform opacity fade.
- In `gestural`, keep one source motion dominant over target anatomy.

## Reject these outcomes

- A filter, full redraw, generic photo mask, or ordinary double exposure
- A target with no credible keystone carrier
- A form completed mainly through invented limbs, joints, facial features, veins, or outlines
- A photograph flattened into texture fill with lost direction or depth
- Effects or fragments that overpower the two readings
- A target choice that becomes plausible only after verbal explanation

Fix target logic, role mapping, or architecture before polishing surface texture.
